# POINTS

极简黑白风格的多人积分管理应用。

## 当前版本

- 响应式网页界面，适配手机与桌面
- 成员添加、改名、积分增加与扣除
- 积分排行榜与最近流水
- 浏览器本地保存，支持基础离线访问
- PWA 基础配置

## 重要说明

当前提交是**可交互的本地 MVP**。多人账号、团队邀请、跨设备云端同步尚未接入。上线联网版前，需要配置 Firebase Authentication / Cloud Firestore，并在服务端规则中校验成员权限和积分流水，不能把浏览器本地数据当作多人共享数据库。

## 本地预览

直接通过静态网页服务器打开 `index.html`。Service Worker 与安装能力需要 HTTPS 或 localhost。

## 路线图

1. 完成界面与本地积分流程
2. 接入账号登录、团队与邀请
3. 接入 Firestore 实时同步及安全规则
4. 完成 Android / iOS 真机适配与测试
5. 发布 Web/PWA，并评估原生打包方案
