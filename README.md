# POINTS

黑白极简风格的积分管理应用，目标平台 Android + iOS。

## 当前版本
- 响应式黑白极简界面
- 成员添加与改名
- 成员积分增加、扣除（不允许扣成负数）
- 团队总积分、成员人数、累计加扣分统计
- 成员积分排行榜
- 最近积分流水
- 独立积分排行榜（展示前五名）
- 成员名称实时搜索
- 成员详情页：个人总积分、累计加分/扣分、全部积分记录
- 自定义团队名称
- 编辑成员时可选择头像颜色（黑白灰色系）
- 积分规则设置：分别配置单次加分与扣分上限，规则随备份保存
- 排行榜可切换前五名或全部成员
- 积分流水可按今天、近 7 天、近 30 天或全部时间筛选
- 支持撤销单条积分流水，撤销时自动反向调整成员积分并移除对应记录
- 成员可设置所属分组，支持按分组筛选成员和排行榜
- 本地自动保存
- JSON 数据备份与恢复
- 删除成员（删除前二次确认，历史流水保留）
- 加分 / 扣分可填写备注，流水中显示备注
- PWA 基础配置与 GitHub Pages 自动部署工作流

## 使用说明
直接通过浏览器打开部署后的网页即可使用。数据保存在当前设备浏览器的本地存储中。
点击“备份”下载 JSON 文件；双击“备份”按钮可选择已有备份文件恢复。导入会替换当前设备的数据，请先确认。

## 重要说明
当前版本是本地单设备版本。不同手机之间不会自动同步，清除浏览器数据也可能导致本地数据丢失，请定期备份。
云端账号、多人实时同步、团队邀请和跨设备数据迁移尚未完成，后续阶段再开发。当前不要求用户注册 Firebase 或 Supabase。
